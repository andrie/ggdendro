# Returns segment, label or leaf-label data from dendro object.

`segment` extracts line segments, `label` extracts labels, and
`leaf_label` extracts leaf labels from a dendro object.

## Usage

``` r
segment(x)

label(x)

leaf_label(x)
```

## Arguments

- x:

  dendro object
