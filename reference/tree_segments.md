# Extract data frame from tree object for plotting using ggplot.

Extract data frame from tree object for plotting using ggplot.

## Usage

``` r
tree_segments(model, uniform, ...)
```

## Arguments

- model:

  object of class "tree", e.g. the output of tree()

- ...:

  ignored
