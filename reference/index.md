# Package index

## Main functions

- [`ggdendro`](ggdendro-package.md)
  [`ggdendro-package`](ggdendro-package.md) : Create Dendrograms and
  Tree Diagrams using 'ggplot2'
- [`ggdendrogram()`](ggdendrogram.md) : Creates dendrogram plot using
  ggplot.

## Extract data

- [`dendro_data()`](dendro_data.md) : Extract cluster data from a model
  into a list of data frames.
- [`dendro_data(`*`<rpart>`*`)`](dendro_data.rpart.md) : Extract data
  from classification tree object for plotting using ggplot.
- [`dendro_data(`*`<tree>`*`)`](dendro_data.tree.md) : Extract data from
  regression tree object for plotting using ggplot.
- [`segment()`](segment.md) [`label()`](segment.md)
  [`leaf_label()`](segment.md) : Returns segment, label or leaf-label
  data from dendro object.

## Helper functions

- [`as.dendro()`](as.dendro.md) : Coerces object to class dendro.
- [`is.dendro()`](is.dendro.md) : Tests whether an object is of class
  dendro.
- [`theme_dendro()`](theme_dendro.md) : Creates completely blank theme
  in ggplot.
