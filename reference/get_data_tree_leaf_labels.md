# Extract labels data frame from tree object for plotting using ggplot.

Extract labels data frame from tree object for plotting using ggplot

## Usage

``` r
get_data_tree_leaf_labels(model, uniform, ...)
```

## Arguments

- model:

  object of class "tree", e.g. the output of tree()

- ...:

  ignored
